# 核心理念

OpenRobot 不是在写一个“能控制机械臂的程序”，而是在构建一个 像人一样感知、思考、行动、学习的通用机器人操作系统。

其中 LLM 是大脑，Skill 是肌肉记忆，WorldModel 是心理模型，ExperienceSystem 是长期记忆，而分层架构保证了复杂任务可被拆解、被调试、被迁移。

  • 跨硬件形态：机械臂、底盘、无人机、四足统一抽象
  • 跨任务域：感知、认知、规划、执行、学习全链路 Skill 化
  • 持续进化：执行即学习，经验自动沉淀并注入决策

关键设计原则

六大原则定义了 OpenRobot 的架构边界与扩展方向。

LLM 是智慧基座，但不直接操作底层

宏观决策由 BDIAgent 负责，微观步骤由 LLMPlanner 通过 ReAct 循环生成。VLM 只输出结构化认知参数，不直接做决策。

一切能力 Skill 化

任何“输入信号 → 输出信号”的算法都封装为 Skill：基础 Skill、复合 Skill、算法 Skill。每个 Skill 自带 schema 自描述，自动生成 OpenAI function schema。

通用硬件抽象层

RobotInterface 作为所有可运动结构的顶层抽象；ManipulatorInterface 作为机械臂专用扩展。同一套逻辑可复用于不同硬件形态。

经验驱动的持续学习闭环

执行轨迹写入 ExperienceLibrary，LLMPlanner 自动检索相关经验并注入 system prompt，实现“做中学”。

真实世界信号全覆盖

SensorChannel 抽象让 RGB、深度、点云、力觉、触觉、IMU、LiDAR、超声波、轮式里程计等信号统一格式进入系统。

仿真 ↔ 实机双模式

YHRGAdapter 自带 Mock 回退；S1_SDK 提供 MuJoCo 可视化仿真；YHRG_control.py 也加入了无头 MuJoCo 仿真，便于无硬件环境下调试。

# 数据流闭环

从用户指令到执行反馈，再到经验沉淀，形成持续学习闭环。

  1. 1 Sensor capture（传感器采集）
  2. 2 WorldModel.ingest()（世界模型更新）
  3. 3 build_state_summary()（状态文本化摘要）
  4. 4 Planner.next_action()（LLM 生成下一步）
  5. 5 SkillRouter.execute()（执行 Skill）
  6. 6 Record step/result（记录执行轨迹）
  7. 7 Update context（更新上下文）
